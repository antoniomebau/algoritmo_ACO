Parámetros y detalle

Prioridades calculadas a partir de los atributos de cada falla.

Qué hace el algoritmo

  1. Cada hormiga construye una ruta factible.
  2. La probabilidad de transición combina feromona y atractivo del destino.
  3. Se calcula T, C y Z para cada ruta completa.
  4. Las rutas con menor Z depositan más feromona.

El CSV contiene las rutas evaluadas en esta sesión.
